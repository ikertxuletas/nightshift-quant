# Como se escribe cada tipo en la ficha

- **Tendencia**: cruce de medias (`{"cruza_arriba": ["EMA(20)", "EMA(50)"]}`) o precio sobre una media (`{">": ["close", "SMA(200)"]}`). La salida suele ser el cruce contrario.
- **Reversion**: umbral en un oscilador, tipicamente `RSI(n)` o `ZSCORE(n)`, con salida cuando el precio vuelve a la media (`{"cruza_abajo": ["RSI(14)", 30]}` de entrada y `{">": ["RSI(14)", 50]}` de salida, por ejemplo).
- **Ruptura**: comparar el cierre con el maximo o minimo previo, siempre con el retardo `[1]` para no contar la vela actual: `{">": ["close", "MAX(20)[1]"]}`. Sin el `[1]` la condicion se compara consigo misma y nunca funciona como ruptura real.
- **Estacionalidad**: no se expresa con condiciones de indicador sino con la seccion `horario`, en concreto `horario.dias` (0 = lunes) y opcionalmente `horario.sesiones` para restringir el rango horario.
- **Momentum transversal**: no usa `entrada`/`salida` sino la seccion `transversal`, con `ranking` (el indicador que ordena el universo, por ejemplo `MOM(126)`), `cada_barras` (frecuencia de rebalanceo) y `top`/`bottom` (cuantos instrumentos se compran o se venden). La ficha lleva `"forma": "transversal"`, no lleva `entrada`, `salida` ni `horario`, `transversal` siempre trae `ranking`, `top` y `cada_barras`, y `gestion` solo admite `tamano` (el stop, el objetivo y el trailing no se aplican en una rotacion). Por ejemplo: `{"tipo": "momentum_transversal", "forma": "transversal", "universo": {"instrumentos": ["SPY", "EFA", "TLT", "GLD"], "plazo": "D1"}, "transversal": {"ranking": "MOM(126)", "top": 2, "cada_barras": 21}, "gestion": {"tamano": {"tipo": "riesgo", "valor": 1}}}`.
- **Volatilidad**: `VOL(n)` se usa normalmente como filtro dentro de una condicion compuesta con `y`, no como señal por si sola: por ejemplo `{"y": [{"cruza_arriba": ["close", "SMA(50)"]}, {"<": ["VOL(20)", 0.02]}]}`.
